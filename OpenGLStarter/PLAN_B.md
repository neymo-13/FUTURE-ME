## สิ่งที่ต้องรู้จากโค้ดของคน A

**Shader (`shader.frag`):** วัตถุของ B ส่ง uniform เหล่านี้ผ่าน `SetSurface()` ทุกครั้งก่อนวาด
- `texture_albedo` = texture unit 0 (ไม่ใช่ `texture2D`)
- `material_ao` = 1.0 (ถ้าเป็น 0 แสง ambient จะหาย)
- `tintColor`: ย้อมเฉพาะพิกเซลขาว/เทา จึงใช้ texture ขาว 1x1 + `tintColor` เป็นสีของแต่ละชิ้น
- `emissiveStrength`: 0 = วัตถุปกติ, 1 = แสดงสี texture เต็มที่ (จอ, รูป)
- shader มีแค่ ambient + diffuse ไม่มี specular
- หลังวาดเสร็จ `RenderDeskScene()` คืนค่า `tintColor = (1,1,1)` และ `emissiveStrength = 0`

**ช่องไฟ `pointLights[4]`:**

| ช่อง | ไฟ | เจ้าของ |
|---|---|---|
| 0, 1 | กองไฟ | A (ตั้งใน `main.cpp`) |
| 2 | จอแล็ปท็อป | B |
| 3 | หน้าต่างรถบ้าน | B |

**พิกัดฉากของ A** (กล้องมองไปทาง -X, ด้านซ้ายของภาพคือ +Z, ด้านขวาคือ -Z)

| สิ่งของ | ตำแหน่ง |
|---|---|
| กองไฟ | (4.5, 0, -9.8) |
| เก้าอี้ | (3.0, 0, -8.5) และ (3.0, 0, -11.0) |
| รถบ้าน | (0, 0, -3) |
| ภูเขา | x = -25 |
| แผ่นแสงเหนือ | x = -200 กว้างจำกัด ถ้า FOV กว้างเกินประมาณ 68° จะเห็นขอบ |
| ระดับพื้นที่ใช้ | y = 0 (วัตถุของ A วางที่ 0 แต่ผิวกล่องหิมะอยู่ที่ -0.45) |

## สิ่งที่ทำแล้ว (รายละเอียด)

### โมเดล (`Models/`)
โมเดลจากเว็บถูกแปลงด้วยสคริปต์: แยกไฟล์ละ 1 สีตาม `.mtl`, ย่อเป็นเมตร, origin กลางก้นวัตถุ
(ไฟล์ต้นฉบับอยู่ใน `*_src/` และ `snowman/` ไม่ถูกแก้)

| ชิ้น | ไฟล์ | ตำแหน่ง/การหมุน |

| แล็ปท็อป | `laptop_body.obj`, `laptop_keys.obj` | DESK + (-0.05, 0.78, 0.25), จอหัน +X อยู่แล้ว |

ถ้าไม่มีไฟล์โมเดล โค้ดจะวาดกล่องแทน (`DrawBox()`)

### quad จาก vertices (`CreateQuad()` ใน `DeskScene.cpp`)
- 4 จุด จุดละ 8 float (P3 N3 UV2) ส่งเข้า `Mesh::CreateMesh()` ของ Lab

### กล้อง (`main.cpp`)
- ค่ามุมล็อก: `LOCK_POS = (8.5, 1.23, -8.0)`, `LOCK_YAW = 176`, `LOCK_PITCH = 0`, `LOCK_FOV = 63`
- เปิดโปรแกรมมาในมุมล็อก กด P เพื่อเดินต่อจากจุดนั้น (WASD + เมาส์)
- กด P อีกครั้งกลับมุมล็อก กดอีกครั้งกลับไปจุดที่เดินอยู่
- ระหว่างล็อก เมาส์ / WASD / scroll ไม่ขยับกล้อง

## งานที่เหลือ (build + รัน + แคปภาพให้ดูหลังจบทุกขั้น แล้วหยุดรอ)

### 1. ไฟจอแล็ปท็อป (ช่อง 2) - เสร็จแล้ว
- `SetDeskLights(Shader*)` ใน `DeskScene.cpp`: จุดไฟอยู่หน้าจอ 15 ซม. ไปทาง +X,
  สี (0.43, 0.78, 1.0) x 2.5 (shader ไม่มีค่าความแรงไฟ จึงคูณที่สี), attenuation 1 / 0.35 / 0.44
- `main.cpp`: เรียก `SetDeskLights(shader)` ต่อจากไฟกองไฟ ก่อน `RenderCampScene()`, `NUM_POINT_LIGHTS = 3`
- เปลี่ยนสีโต๊ะเป็นไม้สีอ่อน (0.55, 0.42, 0.32) เพราะสีน้ำตาลเข้มเดิมแทบไม่สะท้อนแสงฟ้า

### 2. ไฟหน้าต่างรถบ้าน (ช่อง 3)
- หาตำแหน่งหน้าต่างของ `rv3.obj`
- point light สีส้มอุ่น เช่น (1.0, 0.75, 0.45) ในรถ ใกล้หน้าต่าง
- quad เรืองแสงทับหน้าต่าง (วาดใน `DeskScene.cpp` ไม่แก้โมเดลของ A)
- `NUM_POINT_LIGHTS = 4`

### 3. texture ลายไม้โต๊ะ
- โมเดลโต๊ะไม่มี UV จึงทำ quad ผิวโต๊ะทับด้านบน (`CreateQuad()`) แล้วใส่ `Textures/wood.jpg`
- ต้องหาภาพลายไม้มาก่อน

### 4. `CalcPointLight()` (ต้องได้ OK จากคน A ก่อน)
- ย้ายโค้ด point light ใน `main()` ของ `shader.frag` ออกมาเป็นฟังก์ชัน โดยสูตรเหมือนเดิมทุกตัว
  ภาพของ A จึงไม่เปลี่ยน
- ไม่เพิ่ม specular (จะทำให้ฉากของ A เปลี่ยน)

### 5. เก็บงานและส่ง
- แจ้งคน A: แก้ `main.cpp` (ปุ่ม P, มุมเริ่มต้นเป็นมุมล็อก, ไฟช่อง 2-3),
  บั๊กกล้องกระตุกตอนเมาส์เข้าหน้าต่างครั้งแรก, ผิวหิมะต่ำกว่าวัตถุ 45 ซม., โหลด texture 4K ช้า
- รูปใบหน้าจริงใน `frame_photo.jpg`: ถ้ารีโปเป็น public ควรขอความยินยอมเพื่อนในรูปก่อน
- commit + Pull Request เข้า `main`
- แคปภาพ 800x600 จากมุมล็อก: เห็นโต๊ะครบ จอเรืองแสง แสงฟ้าบนโต๊ะ กองไฟ รถบ้าน ภูเขา แสงเหนือ
