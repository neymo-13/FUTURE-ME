# แผนงานคน B: โต๊ะและแล็ปท็อป

ฉาก FUTURE ME: มุมมองบุคคลที่หนึ่ง นั่งหน้าแล็ปท็อปบนโต๊ะพับกลางแคมป์ตอนกลางคืน
มองออกไปเห็นกองไฟ รถบ้าน ภูเขา และแสงเหนือ (ฉากไกลเป็นงานของคน A)

## สิ่งที่ต้องรู้จากโค้ดของคน A

**Shader (`shader.frag`):** วัตถุของ B ต้องส่ง uniform เหล่านี้ทุกครั้งก่อนวาด
- `texture_albedo` = texture unit 0 (ไม่ใช่ `texture2D`)
- `material_ao` = 1.0 (ถ้าเป็น 0 แสง ambient จะหาย)
- `tintColor` = (1,1,1) ปกติ / ใช้ย้อมสีกล่องแทนตอนยังไม่มี texture ได้
- `emissiveStrength` = 0 วัตถุปกติ, 1 = จอเรืองแสง
- shader มีแค่ ambient + diffuse ไม่มี specular

**ช่องไฟ `pointLights[4]`:**

| ช่อง | ไฟ | เจ้าของ |
|---|---|---|
| 0, 1 | กองไฟ | A (ตั้งใน `main.cpp`) |
| 2 | จอแล็ปท็อป | B |
| 3 | หน้าต่างรถบ้าน | B |

ใช้ครบ 4 ช่องแล้ว → `NUM_POINT_LIGHTS` ใน `main.cpp` ต้องเป็น 4

**พิกัดฉากของ A** (กล้องมองไปทาง **-X**, ด้านขวาของภาพคือ **-Z**)

| สิ่งของ | ตำแหน่ง |
|---|---|
| กล้องเริ่มต้น | (7.9, 2.1, -7.4), yaw 178°, pitch 1° |
| กองไฟ | (4.5, 0, -9.8) |
| เก้าอี้ | (3.0, 0, -8.5) และ (3.0, 0, -11.0) |
| รถบ้าน | (0, 0, -3) |
| ภูเขา | x = -25 |
| ผิวพื้นหิมะ | y = -0.45 (กล่อง y=-0.5 scale 0.1) แต่เก้าอี้วางที่ y = 0 → **ต้องเช็กก่อน** |

## พิกัดตั้งต้นของ B (ปรับได้หลังดูภาพจริง)
ให้ `G` = ระดับพื้นจริง (เช็กในขั้น 0)

| แล็ปท็อป | (7.65, ผิวโต๊ะ, -7.55) | เยื้องซ้ายของภาพ จอหันไปทาง +X เอนหลัง 12° |
| แก้ว | (7.75, ผิวโต๊ะ, -8.3) | ขวาของภาพ |

## ขั้นตอน (build + รัน + แคปภาพให้ดูหลังจบทุกขั้น แล้วหยุดรอ)

### ขั้น 0: เตรียม
- เช็กระดับพื้นจริง `G` โดยวางกล่องทดสอบที่ y ต่างๆ
- ใน `DeskScene.cpp` เพิ่ม helper เช็กว่ามีไฟล์โมเดล/texture ไหม เพื่อเลือกระหว่างโมเดลจริงกับกล่องแทน

### ขั้น 1: โมเดลบนโต๊ะ
- โหลด `Models/table.obj`, `laptop.obj`, `mug.obj`, `flowerpot.obj` ด้วย `LoadModelOrBox()`
- ถ้าไม่มีไฟล์: ประกอบจากกล่อง (โต๊ะ = หน้าโต๊ะ + ขา 4 ขา, แล็ปท็อป = ตัวเครื่อง + ฝาจอเอน 12°) แล้วย้อมสีด้วย `tintColor`
- texture: `Textures/wood.jpg` สำหรับโต๊ะ
- แคปภาพจากกล้องชั่วคราว (ยังไม่ commit ค่ากล้อง)

### ขั้น 2: quad หน้าจอแล็ปท็อป
- สร้าง quad 4 vertices เอง (P3 N3 UV2 = 8 float) ผ่าน `Mesh::CreateMesh()`
- วางบนฝาจอ ห่างผิวฝาเล็กน้อยกัน z-fighting
- texture `Textures/screen_code.png`, `emissiveStrength = 1` ให้เรืองแสง

### ขั้น 3: ไฟจอแล็ปท็อป (ช่อง 2)
- เพิ่ม `SetDeskLights(Shader*)` ใน `DeskScene.cpp`
- `main.cpp`: เรียก `SetDeskLights(shader)` ก่อน `RenderCampScene()` (1 บรรทัด) และแก้ `NUM_POINT_LIGHTS`
  (ต้องตั้งก่อนวาดฉากของ A ไม่อย่างนั้นวัตถุของ A จะได้ค่าไฟจากเฟรมก่อน)
- ผ่านเมื่อ: เห็นแสงฟ้าตกบนโต๊ะ แก้ว และกระถาง

### ขั้น 4: ไฟหน้าต่างรถบ้าน (ช่อง 3)
- หาตำแหน่งหน้าต่างของ `rv3.obj` จากภาพ
- point light สีส้มอุ่น เช่น (1.0, 0.75, 0.45) ในรถ ใกล้หน้าต่าง
- quad เรืองแสงทับหน้าต่าง (วาดใน `DeskScene.cpp` ไม่แก้โมเดลของ A)
- `NUM_POINT_LIGHTS = 4`

### ขั้น 5: มุมกล้องสุดท้าย + ปุ่ม P
- `main.cpp`: เพิ่ม `GLFW_KEY_P` ใน `KeyCallback` ของ A → ตั้ง `cameraPos/yaw/pitch/fov` เป็นค่ามุมล็อก
- ระหว่างล็อก `MouseCallback` ต้องไม่หมุนกล้อง (กด P อีกครั้งเพื่อปลดล็อก)
- **บอกคน A ก่อน** เพราะเป็นระบบกล้องของ A

### ขั้น 6: `CalcPointLight()` (ต้องตกลงกับคน A ก่อน)
- ตอนนี้คน A คำนวณ point light ใน `main()` ของ shader แบบมี attenuation + emissive แล้ว
- งานของ B ตามตาราง: ย้ายโค้ดนั้นออกมาเป็นฟังก์ชัน `CalcPointLight()` โดย**สูตรเหมือนเดิมทุกตัว**
  → ภาพของ A ไม่เปลี่ยน แต่แก้ไฟล์ของ A จึงต้องได้ OK ก่อน
- ไม่เพิ่ม specular (จะทำให้ฉากของ A เปลี่ยน)

### ขั้น 7: แคปภาพส่ง
- กด P → แคปภาพ 800x600 → เช็กว่าเห็น โต๊ะครบ จอเรืองแสง แสงฟ้าบนโต๊ะ กองไฟ รถบ้าน ภูเขา แสงเหนือ
